# Sistema de Gestão para Clínica de Fisioterapia

## Sobre o projeto
Sistema web desenvolvido para auxiliar no gerenciamento de uma clínica de fisioterapia.

## Objetivo
Facilitar o cadastro de pacientes, agendamento de consultas e organização dos atendimentos.

## Funcionalidades
- Cadastro de pacientes
- Cadastro de fisioterapeutas
- Agendamento de consultas
- Controle de atendimentos

## Tecnologias
- Java
- HTML
- CSS
- JavaScript
- MySQL
